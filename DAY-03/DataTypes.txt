Python Data Types 
1) Numerical Data Types
int → Whole numbers. Eg: 10, -5
float → Decimal values. Eg: 10.5, 3.14
complex → Real + imaginary parts. Eg: 1+2j

2) Sequential Data Types

String (str) - Collection of characters enclosed in ' ' or " "
Immutable, Ordered, Allows duplicates

List (list) -Collection of elements enclosed in []
Mutable, Ordered, Allows duplicates
Heterogeneous, Dynamic size

Tuple (tuple) - Collection of elements enclosed in ()
Immutable, Ordered, Allows duplicates
Heterogeneous, Fixed size

3) Set Data Types

Set (set) - Collection of unique elements enclosed in { }
Mutable, Unordered, No duplicates
Heterogeneous, Dynamic size

Frozenset (frozenset) - Immutable version of a set
Unordered, Unique elements

4) Mapping Data Type

Dictionary (dict) - Collection of key-value pairs enclosed in { }
Mutable, Ordered, Heterogeneous
Keys are unique, Dynamic size

5) Boolean Data Type - Contains only True or False
Used for conditions and decision-making

6) None Type - None represents absence of a value
Data type: NoneType
